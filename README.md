# Rail Space Shooter

A 3D HTML5 iframe-friendly forward-rail arcade shooter foundation built with Vite, TypeScript, and Babylon.js.

Phase 0 contains only the project foundation: a full-screen Babylon canvas, black space scene, lightweight starfield, camera behind the player, placeholder primitive player ship, movement controls, and a simple HUD. No final assets or future gameplay systems are included yet.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Controls

- Move left/right/up/down with `WASD`.
- Move left/right/up/down with the arrow keys.

## Assets

All assets must be tracked in `docs/ASSET_REGISTER.md`, including licence and commercial-use notes. Phase 0 uses only runtime placeholders and adds no final assets.
