# Rail Space Shooter

A 3D HTML5 iframe-friendly forward-rail arcade shooter foundation built with Vite, TypeScript, and Babylon.js.

The current build contains the project foundation plus Phase 1 player shooting: a full-screen Babylon canvas, black space scene, lightweight starfield, camera behind the player, placeholder primitive player ship, movement controls, pooled placeholder projectiles, and a simple HUD. No final assets are included yet.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Controls

- `WASD` or arrow keys: move.
- `Spacebar`: fire.
- Mouse or touch press: fire one shot.

## Assets

All assets must be tracked in `docs/ASSET_REGISTER.md`, including licence and commercial-use notes. Phase 0 and Phase 1 use only runtime placeholders and add no final assets.
